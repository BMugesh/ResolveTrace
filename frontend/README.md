# ResolveTrace Next.js Frontend

A modern, responsive Next.js 15 + React 19 web application for **ResolveTrace** (SpotifyCares Historical Support Playbook).

## Features
* **Live Decision Agent**: Test customer queries against the live FastAPI decision engine or deterministic calibrated fallback.
* **Complete Ablation Benchmark**: Inspect the 7-system benchmark comparison and metrics lift.
* **Playbook Explorer**: Browse mined historical support pathways, conditions, actions, and evidence.
* **Architecture Diagram**: Understand the 4-phase situation-to-action decision pipeline.

## Getting Started

### Prerequisites
* Node.js 18+
* FastAPI backend running on `http://localhost:8000` (optional, fallback available)

### Run Development Server
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
